# 线稿茶馆

一个线稿风格的 3D 经营小游戏：随机顾客上门点单，玩家在吧台找到对应的饮品/点心送过去赚金币。

## 玩法

- 第一人称视角，WASD 移动，鼠标控制视角，`E` 键拾取吧台上的饮品 / 交付给顾客
- 顾客头顶气泡显示想要的饮品图标和倒计时，超时或送错都会扣一点信誉（❤️）
- 营业额达到 **100 金币** 打烊获胜；信誉扣光则关门大吉
- 结束营业或返回小屋后，咖啡馆营业额会结算进魔女小屋的小金库
- 难度会随营业额缓慢上升：顾客耐心变短、生成间隔变短
- 移动端支持虚拟摇杆移动 + 拖动看方向 + 交互按钮

## 运行

直接用浏览器打开 `index.html` 即可，无需安装或起服务器。

## 文件结构

```
index.html       页面结构，按依赖顺序引入下面的脚本
css/style.css    全部样式
js/scene.js      场景/相机/渲染器、线稿光照材质、几何建模工具、房屋与吧台取货点搭建
js/player.js     玩家移动/碰撞、鼠标锁定与触屏摇杆、缩放、拾取与交付交互
js/customers.js  顾客生成、走位、订单倒计时、结算
js/game.js       音效系统、HUD、开始/结算界面、游戏状态机、主循环
```

`js/` 下几个文件是普通 `<script>`（不是 ES 模块），按顺序加载后共用同一个全局作用域，
所以仍然可以直接双击 `index.html` 用浏览器打开，不需要起本地服务器。

## 技术

- **Three.js r128** + 原生 JavaScript，多文件、经典 `<script>` 引入
- 线稿美术：实体网格叠加 `EdgesGeometry` 黑色描边
- 自定义精简版 GLSL 光照材质：环境光 + 3 个静态点光源
- Canvas 动态贴图：顾客头顶的订单图标 + 倒计时圆环

美术与交互范式（线稿描边、指针锁定第一人称、虚拟摇杆、音效静默降级等）参考并复用自
[《魔女的魔法小木屋》](https://github.com/YIBI2333/line-art-style-magic-cabin)（MIT 协议，作者 YIBI2333）。
