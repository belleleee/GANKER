# 魔女的魔法小木屋

一个线稿风格的 3D 魔法小屋。

[页面预览](https://yibi2333.github.io/line-art-style-magic-cabin/)

操控一只软软的史莱姆在魔法小屋里生活

## 使用

- **HTML**—— 页面结构，按依赖顺序引入样式与脚本
- **Three.js r128**—— 场景、相机、几何体与渲染
- **原生 JavaScript** —— 按结构拆分为多个 `<script>` 文件（见下方文件结构），共用同一份全局作用域
- **自定义 GLSL 着色器** —— 全局 FILL 材质实现自然光效：壁炉炉火、二楼魔法吊灯、9 处室内点光源（坩埚魔火、魔法阵、暖桌、水晶球、蜡烛、星象仪等），物品随昼夜与天气自然变暗、被光照亮
- **Canvas 动态贴图** —— 路牌、便签、黑板、画像等可编辑内容
- **Pointer Lock API** —— 第一人称鼠标视角

## 文件结构

```
index.html                        页面结构，引入 css/style.css 与下面的脚本
css/style.css                     全部样式
js/01-core-setup.js               触屏检测、音效系统、FILL 光照着色器、彩色材质工厂、几何工具、门窗弹簧、壁炉粒子、楼梯、路牌、栅栏
js/02-outdoor-scene.js            室外场景：森林 · 草地 · 石头 · 花 · 萤火虫（含静态合批）
js/03-ground-floor.js             室内陈设工具 + 一楼生活陈设（餐桌·书架·暖桌·猫等）+ 楼梯下储物箱
js/04-bed-desk.js                 二楼陈设 18.1-18.4：大床、床头柜、蜡烛、书桌
js/05-astro-wand.js               二楼陈设 18.5-18.9：星象仪、夜幕、星空粒子、计划板、魔杖
js/06-second-floor-decor.js       二楼陈设 18.10-18.17：衣柜、挎包、魔女帽、时钟、挂画、镜子、地毯、纸箱，以及史莱姆角色本体
js/07-magic-system.js             超位魔法系统：魔杖 + 超级爆裂魔法
js/08-player-controller.js        玩家状态、碰撞体、可交互物清单、输入处理、updatePlayer
js/09-weather-sky.js              天空 · 时间 · 天气系统、星空
js/10-main-loop.js                主循环 animate()
```

这些 `js/*.js` 是普通 `<script>`（不是 ES 模块），按顺序加载后共用同一个全局作用域，拆分严格保持原文件的代码顺序，未挪动任何逻辑，所以仍然可以直接双击 `index.html` 用浏览器打开，不需要起本地服务器。

## 玩法

- 三种视角切换：固定 / 第三人称 / 第一人称
- 昼夜循环，时刻与时间流速可调
- 七种天气：晴、多云、雾、雨、暴雨、雪、暴雪，支持随机轮换
- 室内光照可交互：壁炉、吊灯可点燃熄灭，光源强度随火焰闪烁
- 可编辑内容：路牌文字、便签文字、墙上画像的图片链接
- 楼内陈设：原木餐桌、暖桌、书架、大魔女坩埚、塔罗牌桌、大床、书桌、星象仪、月光盆栽……

## 操作

| 按键 | 动作 |
| --- | --- |
| WASD / 方向键 | 移动 |
| Shift | 疾跑 |
| 空格 | 跳跃（可以跳上桌椅床凳） |
| E | 交互（门窗、壁炉、编辑文字） |
| 1 / 2 | 空手 / 魔杖 |
| 鼠标 | 视角（第三 / 第一人称） |
| Esc | 退出鼠标锁定 |
| 右上角 ● | 菜单 |

移动端：虚拟摇杆移动，右侧按钮为跳跃 / 交互 / 疾跑 / 施法。
