# 发家之路：线稿风格魔女小屋

一个线稿风格的 3D 魔法小屋经营小游戏。玩家操控一只史莱姆在小屋、农田、商店和咖啡馆之间活动，通过种植、收获、经营咖啡馆、购买种子和存档推进自己的“发家之路”。

项目基于 Three.js r128 与原生 JavaScript 开发，所有脚本以普通 `<script>` 方式按顺序加载，可以直接用浏览器打开本地页面运行。

## 页面入口

- `index.html`：展示页，包含项目介绍、注册 / 登录、成员介绍和进入游戏入口。
- `game.html`：主游戏页面，进入魔女小屋、农田、商店、报刊和小金库系统。
- `line-art-cafe/index.html`：线稿茶馆小游戏，咖啡馆营业收入会回到小屋后存入小金库。

## 主要功能

- 展示页与游戏页分离：展示页负责介绍和入口，游戏页负责实际游玩。
- 注册与登录：不同账号拥有独立本地存档。
- 存档系统：保存玩家位置、天气时间、房屋状态、金币、仓库、背包、农田、报刊和故事进度。
- 成员介绍：六位成员头像公转展示，可点击进入个人介绍。
- 小金库系统：金币可以通过收获作物、咖啡馆经营、故事投资等方式累计。
- 种植系统：翻地、播种、浇水、成长、收获萝卜。
- 背包系统：商店购买的萝卜种子会进入背包，播种时消耗种子。
- 作物仓库：收获后的萝卜进入仓库。
- 商店系统：货架货箱可打开，开箱后按 `B` 消耗金币购买萝卜种子。
- 咖啡馆系统：完成顾客订单赚取营业额，返回小屋后收入自动进入小金库。
- 报刊系统：在小屋中阅读更新说明和世界信息。
- 天气与昼夜：支持晴、多云、雾、雨、暴雨、雪、暴雪，以及时间流速调整。
- 室内交互：门窗、壁炉、吊灯、便签、路牌、画像、书本、家具等可交互对象。

## 操作方式

| 按键 | 动作 |
| --- | --- |
| WASD / 方向键 | 移动 |
| Shift | 疾跑 |
| 空格 | 跳跃 |
| E | 交互 |
| B | 在打开的商店货箱旁购买萝卜种子 |
| 1 | 空手 / 播种 |
| 2 | 魔杖 |
| 3 | 锄头 |
| 4 | 水壶 |
| 5 | 镰刀 |
| V | 第三人称 / 第一人称切换 |
| F / 鼠标右键 | 施法 |
| Esc | 退出鼠标锁定或关闭弹窗 |
| 右上角 ● | 打开设置菜单 |

移动端支持虚拟摇杆移动，右侧按钮用于疾跑、跳跃、交互和施法。

## 运行方式

直接用浏览器打开：

```text
index.html
```

如果只想测试主游戏，也可以打开：

```text
game.html
```

如果浏览器限制本地文件访问，可以在项目目录启动一个本地静态服务器：

```bash
python3 -m http.server 8000
```

然后访问：

```text
http://127.0.0.1:8000/
```

## 技术说明

- Three.js r128：场景、相机、几何体、材质与渲染。
- 原生 JavaScript：多脚本拆分，共用全局作用域。
- 自定义 GLSL 材质：实现室内外光照、昼夜变化和点光源效果。
- Canvas 动态贴图：用于路牌、便签、画像、报刊等可变内容。
- LocalStorage：用于账号、存档、小金库、背包和咖啡馆收入结算。
- Pointer Lock API：用于第一人称视角控制。
