# 《发家之路》交互故事站点

静态网页作业 Version 1.0。直接在浏览器打开 `index.html` 即可预览。

## 页面清单

- `index.html`：首页
- `story.html`：游戏档案与玩法说明
- `level-1.html` 至 `level-3.html`：三章关卡故事
- `login.html`、`register.html`：登录与注册演示
- `team.html`：小组介绍
- `member-a.html` 至 `member-c.html`：成员个人介绍页

## 提交前

将成员页中的占位姓名、头像和分工替换为真实信息。可把 `.avatar` 区块替换为 `<img>` 标签，使用成员本人照片。完成后将整个 `发家之路` 文件夹压缩为 `.rar` 文件提交。
