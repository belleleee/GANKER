# 序章设计：出生情节 + 农场/茶场篇（详细版）

> 说明：本章节所有人物对话均为原创改编创作，用于游戏叙事，不是真实人物的逐字引语。
> 主角以真实历史原型为灵感，但姓名、具体台词均做了文学化处理，避免版权与真实性风险。
> 除主角外，其余人物均为虚构或复合创作角色，不对应任何真实姓名。

---

## 一、NPC 角色档案（详细版）

### 1. 母亲（阿娟）

- **外貌**：常年穿着洗得发白的蓝布衫，手指因常年握粉笔而有薄茧，走路总是很快，像是在跟时间赛跑
- **背景**：家道中落前是殷实人家的女儿，读过几年书，家道中落后靠这点文化在小学谋了个教职，成了全家唯一稳定的收入来源
- **性格核心**：外表严厉、说话直接，甚至有点刻薄，但所有的刻薄背后都是"怕你走弯路"的焦虑。从不当面夸奖，但会在你不知道的时候，把她自己那份口粮匀给你
- **口头禅**："日子是过出来的，不是想出来的。"
- **隐藏的秘密/内心冲突**：她其实一直觉得对不起丈夫——嫁过来是奔着体面日子去的，结果一辈子清贫。这份愧疚，全部转移到了"一定要把孩子拉扯出息"这件事上
- **在剧情中的作用**：序章开场引导者；农场篇中会通过书信往来间接出场（见"家书"支线）；返城节点的关键人物（退休后主角接她的班，这是主角命运转折的直接触发点）
- **人物弧光**：从"严厉的现实主义者"到剧情尾声流露出一次罕见的脆弱——得知儿子决定辞去安稳工作去创业时，她的反应会成为一个重要的情感节点（这个留给"返城创业"篇处理）
- **关系值机制**：`mother_bond`，初始50，影响后期"是否愿意为家庭牺牲个人选择"的分支解锁

### 2. 父亲（老宗）

- **外貌**：清瘦，背有点驼，一双手常年闲不住地修修补补家里的旧物件，仿佛只有这样才能证明自己还有点用
- **背景**：曾是旧政府里一个不大不小的职员，识文断字，写得一手好字，新旧交替之后彻底失去了立足之地，此后再没找到过正经工作
- **性格核心**：沉默寡言，带着旧文人式的、近乎倔强的自尊心。他从不主动提过去，但偶尔喝了点酒，会喃喃念叨几句年轻时候的事
- **口头禅**（罕见开口时）："这世道，认命的人活得，不认命的人也活得，就是活法不一样。"
- **隐藏的秘密/内心冲突**：他其实一直暗中观察儿子，把自己没能实现的"翻身"寄托在儿子身上，但碍于自尊，从不说出口
- **在剧情中的作用**：出场次数少而精，每次出场都是"一句话定基调"式的存在。农场篇中会有一封"父亲亲笔写的家书"，是全篇最柔软的一处细节
- **关系值机制**：`father_bond`，与`mother_bond`独立计算，某些分支选择会让二者此消彼长（比如"抱怨出身"的选择会拉近与父亲的距离，但让母亲觉得你"不知足"）

### 3. 阿海（本名：陈志海，农场知青伙伴）

- **外貌**：圆脸，爱笑，笑起来有两个浅浅的酒窝，身形偏瘦弱，干重活明显比别人吃力
- **背景**：家里是杭州同一条街上开裁缝铺的，从小娇生惯养，是家里最小的孩子，从没吃过什么苦
- **性格核心**：表面乐天派，嘴上永远有说不完的笑话，是整个知青队伍的"开心果"。但这份乐观是撑出来的，遇到真正的绝境，最先垮掉的往往是他
- **口头禅**："大不了就是个死，怕什么！"（嘴上这么说，其实最怕的就是这个）
- **隐藏的秘密/内心冲突**：他偷偷藏着一张全家福，每晚都要摸一摸才能睡着；他其实早就写好了"申请返城"的信，一直没敢寄出去
- **在剧情中的作用**：农场篇章的核心分支NPC，代表"另一种可能的命运"；他的结局走向由玩家选择间接决定，用于制造"如果我当初..."的情绪冲击
- **人物弧光**：
  - **留下分支**：阿海被主角说服留下，此后性格逐渐变得坚韧，多年后成为主角创业初期最早跟随的伙伴之一（呼应真实历史中"蹬三轮车创业"阶段身边总要有个帮手的设定）
  - **离开分支**：阿海选择返城，此后杳无音讯，多年后在"创业成功"的某个新闻发布会现场，会有一个若有若无的镜头——人群中一个神似阿海的背影，一闪而过，不做任何解释，留给玩家自己回味
- **关系值机制**：`ahai_bond`

### 4. 队长老陈（生产队干部，本名：陈建国）

- **外貌**：皮肤黝黑粗糙，常年叉腰站在田埂上，嗓门洪亮，一开口整个田头都能听见
- **背景**：本身也是最早一批下乡的知青，只是因为吃苦耐劳被提拔成了基层干部，某种程度上是"混得比较好的自己人"，而不是外来的压迫者
- **性格核心**：表面刻板严厉，动辄以"完不成任务就别吃饭"这种话威胁人，但骨子里认这个理：谁肯下死力气干活，他就认谁
- **口头禅**："在我这儿，没有'干不完'三个字，只有'想不想干'。"
- **隐藏的秘密/内心冲突**：他自己也曾是那个"差点扛不住"的年轻人，只是熬过来了，所以对"喊苦"的年轻人格外没有耐心——某种程度上，他的严厉是一种扭曲的"为你好"
- **在剧情中的作用**：制造压力的角色，同时是主角"隐忍值"或"谈判技巧"数值积累的核心触发点；茶场篇后段会有一场"老陈私下认可主角"的隐藏对话，揭示他刻薄外表下的真实想法
- **关系值机制**：`chen_respect`（老陈的认可度），达到阈值解锁隐藏对话

### 5. 秀兰（茶场女知青，本名：李秀兰）

- **外貌**：扎着一根粗麻花辫，手上有常年劳作磨出的茧，笑起来眼睛弯成一条缝，说话轻声细语但透着一股韧劲
- **背景**：和主角一样因为下乡耽误了原本的人生轨迹（原本家里给说了一门亲事，因为下乡不了了之），是那种"把苦日子过成过日子"的类型
- **性格核心**：平实、坚定，不抱怨、不诉苦，用行动而不是语言表达关心——比如永远第一个把热水递到最需要的人手里
- **隐藏的秘密/内心冲突**：她心里其实一直记挂着家里托人捎来的口信——年纪不小了，家里催她相看人家，她一直用"再等等"拖着，心里其实是在等一个人
- **在剧情中的作用**：茶场篇章尾声出场，为后续"成家"节点做铺垫；不挂钩主线数值，纯粹是叙事温度的调剂
- **人物弧光**：从"送一碗热水的陌生人"到"两人在艰苦岁月里彼此扶持"，最后一幕是父母捎来家具、暗示成家的场景，秀兰会有一句意味深长的回应

### 6. 二丫（虚构新增角色，茶场知青，本名：周雅琴）

- **外貌**：留着利落的短发，说话嗓门大，动作风风火火
- **背景**：家里成分比主角还要"糟糕"，父亲曾被批斗过，她比谁都清楚"认命"两个字有多重
- **性格核心**：愤世嫉俗，嘴上永远在抱怨这个不公平的世道，但抱怨归抱怨，干起活来从不含糊——她的"嘴硬心软"和阿海的"嘴甜心软"形成鲜明对比
- **口头禅**："别指望这世道能给你什么公道，公道都是自己抢出来的。"
- **在剧情中的作用**：**代表"愤怒而非隐忍"的另一种应对方式**，与主角形成价值观碰撞——如果玩家选择"据理力争"路线，二丫会成为一个隐性的"同路人"，两人会有一段惺惺相惜的对话；如果玩家选择"硬扛不抱怨"路线，二丫则会评价主角"活得太憋屈"，形成价值观层面的张力
- **关系值机制**：`erya_bond`，与`negotiation_skill`（谈判技巧）数值联动——高谈判技巧分支会自动提升与二丫的关系值

### 7. 赵伯（虚构新增角色，茶场老工人）

- **外貌**：满脸皱纹，背有点驼，抽着自己卷的旱烟，说话慢悠悠，但每句话都像是想了很久才说出口
- **背景**：茶场资历最老的工人，见过太多批知青来了又走，是那种"看透了但不说破"的角色
- **性格核心**：话不多，但每次开口都像是点拨——他不直接告诉你该怎么做，只是讲一个看似不相关的小故事，让你自己悟
- **在剧情中的作用**：**"智慧长者"型角色**，在主角情绪低谷（比如阿海离开后、或者被老陈刁难后）适时出现，起到情绪缓冲和价值观引导的作用，同时埋下"专注做好一件事，比什么都强"这类朴素道理的伏笔，呼应主角日后的经营理念
- **关键台词**（举例）："我在这片地上待了三十年，见过的人，能干成事的，往往不是最聪明那个，是最不嫌麻烦、肯把一件事做到底那个。"

## 二、序章：出生情节（扩写版）

### 场景1：开场独白

背景：昏暗的老照片质感画面，文字逐句淡入，配轻缓的钢琴/古筝配乐

> "旧时代的尾巴，扫到了这个家。祖辈做过官，到父亲这一代，只剩下一份体面却挣不到钱的差事——很快，连这份差事也没了。母亲在小学教书，一份微薄的工资，要喂饱五张嘴。"

### 场景2：父亲与母亲的对话（新增，展现家庭氛围）

```
【母亲】（就着油灯缝补衣服，头也不抬）
"米缸又见底了。"

【父亲】（沉默地修着一把断了腿的凳子，许久才应声）
"我知道。"

【母亲】（叹气）
"你知道有什么用。"

【父亲】（手上的动作停顿了一下，没有反驳，继续修凳子）
```

> "这样的对话，你从小听到大。你渐渐明白，在这个家里，'知道'和'能做到'，中间隔着一整个时代的沟壑。"

### 场景3：儿时片段（蒙太奇式文字，快速推进）

> "你走街串巷叫卖过炒米，寒冬腊月的火车站，也卖过热气腾腾的煮红薯。挣的钱不多，但那是你第一次知道，自己的力气能换来点什么。"

### 场景4：师范学校的希望与落空（扩写，增加一段细节）

```
【你】（攥着录取通知书，第一次感觉离命运近了一步）
"我考上了！不要学费，还有津贴！"

【居委会办事员】（面无表情地翻看档案）
"家庭成分……不符合条件。这个名额，给不了你。"
```

> "那张录取通知书，你后来烧掉了。不是气话，是你想明白了——留着它，只会让往后的每一天都更难熬。"

### 场景5：命运的转折（引出主线）

```
【邻居王婶】（急匆匆跑来敲门）
"听说了吗？舟山那边的农场，招知识青年，不问家庭成分，
谁都能报名！"

【你】（心跳骤然加快）
"……真的不问出身？"

【王婶】
"千真万确！我娘家侄子已经报上名了。"
```

> "那一刻，你第一次觉得，这个世道，好像终于给你留了一道缝。"

## 三、第一幕：马目农场篇（扩写版，含多个分支）

### 开场

```
【旁白】
1963年，18岁。一纸通告贴在墙上：
"舟山马目农场，招收知识青年，不论家庭成分。"
这行字，你看了三遍。
```

### 分支点1：报名的态度

| 选项 | 台词 | 数值影响 |
|---|---|---|
| A. 义无反顾报名 | "别的路都堵死了，这条路，我认了。" | `resilience +10`，`ahai_bond +5` |
| B. 犹豫但报名 | "至少……这是一条能走通的路。" | `resilience +5` |
| C. 抱怨着报名 | "凭什么我们这种出身，只能捡剩下的路走？" | `resilience +5`，`father_bond +5` |

### 场景：初到农场

> "马目农场，从前是关押犯人的地方，本地人叫它'舟山西伯利亚'。荒滩、盐碱地、望不到头的活儿——挖沟、修坝、拉土堆石，没有一样是轻省的。"

### 新增场景：与阿海初次相识

```
【阿海】（凑过来，笑嘻嘻地递过来半块饼）
"哥们儿，一看你就是本地口音，杭州哪条街的？"

【你】（接过饼，有些意外）
"上城区。"

【阿海】
"嚯，同乡！以后我罩着你——啊不对，是咱俩互相罩着。"
```

> "这是你和阿海认识的第一天，谁也没想到，这份'互相罩着'的承诺，会在几个月后被真正考验。"

### 新增场景：围垦劳动的艰辛（细节铺垫，为后续崩溃夜做情绪蓄力）

> "围垦滩涂种棉花，是所有活里最磨人的一种——海水倒灌，辛苦种下的苗，一场大潮就能全部泡烂。这一年，收成差到几乎绝收，队里连基本的口粮都快发不出来。"

### 分支点2：阿海的崩溃夜（关键情节）

```
【阿海】（深夜，压低声音，声音发颤）
"我撑不住了……我想跟家里说，我要回去。哪怕回去挨骂，
也比在这儿看不到头强。"

【阿海】（从贴身的口袋里掏出一张全家福，手在抖）
"我娘每次来信都问我什么时候回去，我……我是不是特别没出息？"
```

| 选项 | 你的台词 | 效果 |
|---|---|---|
| A. 鼓励他坚持 | "再撑一撑。这地方要熬出个人样，得先熬过这一关。" | `ahai_bond +15`；解锁"阿海留下"分支 |
| B. 理解并支持他离开 | "想清楚了就走吧，没人能替你扛这些。" | `ahai_bond +5`；解锁"阿海离开"分支 |
| C. 沉默不语，只是递给他一支烟 | （无台词，纯动作） | `resilience +5`，`ahai_bond +10`（暧昧处理） |

### 新增场景：分支后续差异化处理

**若选择A（鼓励坚持）：**
```
【阿海】（抹了把脸，勉强笑了笑）
"行……行，我再撑撑。你小子，嘴上没个正经，关键时候倒是靠谱。"
```
> 此后阿海性格逐渐发生变化，从"嘴甜心软"慢慢变得沉稳，多年后会成为你创业路上第一个愿意跟着你一起蹬三轮的人。

**若选择B（支持离开）：**
```
【阿海】（红着眼眶，用力点头）
"谢了。真的……谢了。"
```
> 三天后，阿海办好了手续，临走前把那张全家福塞给了你："留个念想，等你也回去了，来找我。"
> 你再也没等到那一天的到来——直到很多年后。

### 收尾：被评为"积极分子"

> "别人熬一天算一天，你却憋着一股劲——修坝的时候比谁都卖力，评先进的时候，你的名字被念了出来：'舟山地区上山下乡积极分子'。这大概是你人生第一张，靠自己挣来的奖状。"

## 四、第二幕：绍兴茶场篇（扩写版，跨度压缩至"数年"叙事）

### 转场

```
【旁白】
一年后，马目农场收缩。你和一批人，
被转去了绍兴的茶场。这一待，就是十几年。
```

### 场景：日复一日的劳动清单

> 种茶、割稻、造地、开山打石、挖盐晒盐——你几乎干遍了这片土地上能想到的所有苦力活。唯一不变的，是手里那本翻烂了的《毛选》，是你在漫长岁月里，唯一能反复咀嚼的读物。

### 新增场景：与二丫的初次碰撞（价值观冲突铺垫）

```
【二丫】（甩着锄头，语气冲）
"你这么卖力干活给谁看？队长又不会因为这个多给你一口饭吃。"

【你】（可选择的回应）
选项A："多干点，总没坏处。"
选项B："我信一句话——出头的椽子先烂，但缩着的椽子，一辈子也就是根椽子。"
```

> 如果选择B，二丫会愣一下，随即咧嘴一笑："这话，倒是有点意思。" ——`erya_bond +10`

### 分支点3：队长老陈的刁难

```
【队长老陈】（叉着腰，故意刁难）
"这批稻子，今天必须割完。割不完，晚饭别想吃。"
```

| 选项 | 台词 | 效果 |
|---|---|---|
| A. 硬扛，不抱怨 | "割就割，饭迟点吃没什么大不了。" | `resilience +15` |
| B. 据理力争 | "这个工作量，一个人根本干不完，得加人手。" | `resilience +5`，`negotiation_skill +10` |
| C. 私下摸鱼应付 | "差不多就行，谁看得出来。" | `resilience -5` |

### 新增场景：老陈的反应差异化

**若选择B（据理力争）：**
```
【队长老陈】（皱眉，沉默片刻）
"……行。老周，你带两个人过去帮忙。"
（旁白：这是你第一次发现，敢开口要条件的人，未必吃亏）
```
> `negotiation_skill +10` 这个隐藏数值正式解锁，为后续"承包谈判"关卡预埋伏笔。

### 新增场景：赵伯的点拨（情绪低谷后的缓冲）

**触发条件**：`resilience` 低于阈值，或阿海离开分支之后

```
【赵伯】（蹲在田埂上，慢悠悠抽着旱烟）
"年轻人，愁眉苦脸干活，跟乐呵呵干活，累的程度是一样的。
你说，那图个啥？"

【你】
"……那还能图个啥。"

【赵伯】
"我在这片地上待了三十年，见过的人，能干成事的，
往往不是最聪明那个，是最不嫌麻烦、肯把一件事做到底那个。"
```

> 这段对话不产生数值影响，纯粹是情绪缓冲和价值观埋伏笔，为主角日后"专注主业，小步快跑"的经营理念做铺垫。

### 情感支线：秀兰登场（扩写为三个小场景）

【秀兰】（递给你一碗热水）

【秀兰】（一边插秧一边随口说）

**场景三：家具送来（呼应真实历史细节，情感高潮）**

## 五、数值与分支设计说明（更新版）

| 数值 | 触发来源 | 后续用途 |
|---|---|---|
| `resilience`（坚韧值） | 多个分支累加 | 影响"广告豪赌""兼并谈判"等关卡的抗压成功率 |
| `ahai_bond`（阿海关系值） | 崩溃夜分支 | 决定阿海是否以配角身份出现在创业篇章 |
| `father_bond` / `mother_bond` | 序章+零星分支 | 影响"返城创业"篇里家庭态度相关的分支解锁 |
| `negotiation_skill`（谈判技巧，隐藏） | 仅"据理力争"分支解锁 | 直接加成"承包谈判"关卡（田忌赛马机制） |
| `erya_bond`（二丫关系值） | 价值观选择联动 | 与`negotiation_skill`挂钩，暂无独立后续剧情，可作为彩蛋支线 |
| `chen_respect`（老陈认可度） | 多次"硬扛/据理力争"选择累加 | 达到阈值解锁老陈的隐藏认可对话 |

## 六、这一段的定位提醒

这一整段（出生情节+农场+茶场）建议控制在**8-10分钟阅读量以内**（比初版略有增加，因为角色更丰满了），原因：

1. 增加的内容（二丫、赵伯、秀兰的三段式情感线）是为了让序章不再是单调的"苦难流水账"，用多个性格迥异的NPC制造情绪起伏
2. 每个新增角色都承担了明确的功能性作用（二丫→价值观碰撞、赵伯→情绪缓冲与理念埋伏笔），不是为了丰满而丰满
3. 核心玩法（决策+事件、策略对抗、解谜）仍然在"返城创业"之后才正式展开，序章的作用始终是"建立情感代入感和角色初始属性"
