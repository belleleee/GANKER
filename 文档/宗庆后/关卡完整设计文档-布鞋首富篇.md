# 关卡完整设计文档：《布鞋首富》篇

> 整合此前所有讨论（人物素材、时间线、序章设计、三大核心机制），
> 是这一关卡从开场到结局的完整设计说明。

---

## 一、关卡总览

**关卡代号**：布鞋首富
**改编原型**：宗庆后真实创业史（1945-2009，聚焦创业黄金期）
**核心气质**：大器晚成、孤注一掷、脚踏实地
**预计游玩时长**：序章8-10分钟 + 正片六个场景约20-25分钟

### 整体结构

```
序章（出生+农场+茶场，纯叙事为主，少量分支）
    ↓ 携带数值：resilience / negotiation_skill / ahai_bond / father_bond / mother_bond
返城过渡（简短，衔接序章与正片）
    ↓
正片场景1：承包谈判（田忌赛马机制）
    ↓
正片场景2：广告豪赌（决策+事件机制）
    ↓
正片场景3：兼并国企（决策+事件机制，含数字对比）
    ↓
正片场景4：非常可乐大战两乐（田忌赛马机制·换皮复用）
    ↓
正片场景5：达能之争（线索解谜机制）
    ↓
正片场景6：联销体推行（决策+事件机制·收尾）
    ↓
金币结算 → 结局判定（好结局 / 阶段性成就结局）
```

**设计原则**：全程只用**三套核心机制**反复复用换皮，不为每个场景单独发明新系统——这是此前反复讨论后收敛出的方案，保证开发工作量可控。

## 二、三大核心机制详细设计

### 机制A：决策+事件系统（覆盖场景2、3、6）

**运作逻辑**：
```
显示新闻/事件描述 → 玩家从2-3个选项中选择 → 结算数值变化（部分含随机成功率）→ 显示结果反馈 → 进入下一事件
```

**技术实现要点**（对应你已掌握的知识）：
```javascript
function showEvent(event) {
    // 用 DOM 操作渲染事件描述和选项按钮
    document.getElementById('event-text').textContent = event.description;
    // 用 forEach 动态生成选项按钮
    event.options.forEach(opt => {
        const btn = document.createElement('button');
        btn.textContent = opt.label;
        btn.addEventListener('click', () => resolveEvent(opt));
        document.getElementById('options-container').appendChild(btn);
    });
}

function resolveEvent(option) {
    if (option.successRate) {
        const roll = Math.random();
        if (roll < option.successRate) {
            applyEffect(option.successEffect);
        } else {
            applyEffect(option.failEffect);
        }
    } else {
        applyEffect(option.effect); // 无随机成分，直接结算
    }
}
```

### 机制B：策略对抗系统（"田忌赛马"式，覆盖场景1、4）

**运作逻辑**：
```
玩家看到己方3个"筹码"（资源/产品/说辞） → 对手的3个筹码信息部分可见部分隐藏
    → 玩家自由分配己方筹码去对抗对手筹码 → 逐一结算胜负 → 综合结果决定本场收益
```

**技术实现要点**：
```javascript
const playerChips = [
    { name: '价格优势', power: 7 },
    { name: '渠道网络', power: 9 },
    { name: '广告声量', power: 5 }
];
const opponentChips = [
    { name: '品牌积淀', power: 8 },
    { name: '技术壁垒', power: 6 },
    { name: '资金实力', power: 9 }
];
// 玩家通过拖拽或点击选择"哪个筹码对哪个"，用数组下标匹配后比较 power 值
// 三场比较结果（赢/输次数）决定本场整体是"大胜/险胜/惜败/惨败"
```

**场景1（承包谈判）的筹码设计**：
- 己方：`肯吃苦`、`敢承诺`、`懂门路`
- 对方（评审/竞争者）：`资历`、`关系户背景`、`保守稳妥`
- 呼应真实历史：主角敢喊出"10万元"利润承诺（对应`敢承诺`筹码），这是他能赢得机会的关键筹码

**场景4（非常可乐vs两乐）的筹码设计**：
- 己方：`价格优势`（比两乐低0.6元）、`联销体渠道`（下沉市场覆盖）、`本土口味`（更甜，符合下沉市场偏好）
- 对方：`品牌积淀`、`资金实力`、`一二线城市渠道`
- 呼应真实历史：正是靠"农村包围城市"策略（渠道+价格+口味的组合拳）打赢这一仗，而不是正面硬刚对方的强项（品牌、资金）

### 机制C：线索解谜系统（覆盖场景5）

**运作逻辑**：
```
展示一份"简化版合同条款"文本 → 其中1-2句话是"陷阱"（对己方不利/表述模糊）
    → 玩家需要点击/选中可疑句子 → 判断是否找对 → 找对越多，后续谈判筹码越有利
```

**技术实现要点**：
```javascript
const contractClauses = [
    { text: "双方共同享有商标使用权", isTrap: false },
    { text: "如需商标转让，须提交合资公司董事会审议", isTrap: true },  // 真实历史里的关键陷阱条款
    { text: "投资款项将分期到位", isTrap: false }
];
// 每个条款渲染成可点击的 <p>，点击后 classList.toggle('selected')
// 提交后比对玩家选中的条款与 isTrap 标记，计算找对了几条
```

**内容来源**：直接改编自宗庆后素材文档里"达能之争"部分真实存在的"阴阳合同"条款细节，教育意义最强的一段——玩家实际在学习"如何识别合同里的模糊表述"。

## 三、正片场景详细设计

### 场景1：承包谈判（1987年）

- **机制**：策略对抗（田忌赛马）
- **背景文案**：
  > "文教局要对下属经销部实行承包，谁能保证更高的利润，机会就给谁。别人报的都是4万、5万，你盘算了一夜，做了一个所有人都觉得疯了的决定。"
- **对局展示**：玩家 vs 另一位"关系户"竞争者，赢下这场对抗即可拿到经销部承包权
- **胜负结算文案**（大胜）：
  > "'10万元。'你说出这个数字时，办公室里安静了两秒。文教局的人对视一眼——这个疯子，要不就成，要不就死得很惨。"
- **数值影响**：胜利解锁经销部经营权（进入场景2的前提），`negotiation_skill` 提供加成

### 场景2：广告豪赌（1988年）

- **机制**：决策+事件（含随机成功率）
- **背景文案**：
  > "杭州电视台开出21万元的广告费，这个数字，是你全部的家底。签下去，可能一夜翻身；打了水漂，可能就此关门。"
- **选项**：
  - `[签下广告合同，All in]`（成功率60%，参考真实历史高概率成功，但保留悬念）
    - 成功：`cash × 5`，触发"订单剧增"过场文案
    - 失败：`cash × 0.2`，触发"背水一战"文案，进入紧张但非致命的低谷状态
  - `[保守做法，靠口碑慢慢积累]`（无随机成分）
    - `cash × 1.5`（稳定但增长有限）
- **`resilience`数值联动**：如果序章`resilience`值较高，失败后的`cash`损失可以打折（呼应"抗压能力"设定）

### 场景3：兼并国企（1991年）

- **机制**：决策+事件（含数字对比UI）
- **背景文案**：
  > "杭州罐头厂，2200多名职工，资不抵债。你自己的厂，只有140人。面前三条路。"
- **选项**（直接对应真实历史三选一）：
  | 选项 | UI展示的预期数据 | 实际效果 |
  |---|---|---|
  | 联营 | 预期回报：低，风险：低 | `cash × 1.2`，无声誉变化 |
  | 租赁 | 预期回报：中，风险：低 | `cash × 1.4`，`reputation +5` |
  | 有偿兼并（8000万） | 预期回报：高，风险：高 | 短期`cash -大幅`，3回合后`cash × 3`，`reputation +15`（但初期`reputation -10`，因"老员工反对"） |
- **呼应真实历史**：有偿兼并是唯一能触发"后续非常可乐大战"高数值起点的选择，鼓励玩家承担风险，但另外两个选项也能"稳妥地"继续游戏（不是唯一正确答案，避免"标准答案感"）

### 场景4：非常可乐大战两乐（1998年）

- **机制**：策略对抗（田忌赛马·换皮复用场景1机制）
- **背景文案**：
  > "已经有七个中国品牌，倒在了'两乐'脚下，业界叫这个'水淹七军'。所有人都说，你这是鸡蛋碰石头。"
- **对局展示**：三组筹码对抗（价格/渠道/口味 vs 品牌/资金/一二线渠道）
- **胜负结算文案**（大胜）：
  > "'非常可乐，中国人自己的可乐！'广告喊出来的那天，没人再敢说这是笑话。三年后，你们的可乐，卖到了美国。"
- **数值影响**：`cash × 4`（如果场景3选择了"有偿兼并"，此处有额外倍率加成，体现"资源积累的复利效应"）

### 场景5：达能之争（2007年，压缩年代跨度）

- **机制**：线索解谜
- **背景文案**：
  > "合作了十年的外方股东，突然翻出一份合同，说要用40亿低价拿走你亲手做大的资产。你把当年签的合同翻了出来，一字一句地看。"
- **玩法**：呈现5-6条简化合同条款，其中2条是真正的陷阱，玩家选出可疑条款
- **结算**：
  - 全部找对：`cash`不受任何损失，`reputation +20`（"绝地反击"文案）
  - 部分找对：`cash`小幅损失，但仍保住控制权
  - 全部找错：`cash`大幅损失，触发"惨胜"文案（保住公司但元气大伤）

### 场景6：联销体推行遇阻（收尾场景）

- **机制**：决策+事件（管理类收尾）
- **背景文案**：
  > "你想把'先打款后发货'定成规矩，几乎所有经销商都在骂娘。有人说你疯了，有人说你不近人情。"
- **选项**：
  - `[强硬推行到底]`：短期`reputation -15`，但3回合后`cash × 2`（呼应真实历史"最终建成庞大网络"）
  - `[部分妥协，逐步推行]`：`reputation`不变，`cash × 1.3`（更稳但收益打折）
- **收尾**：本场景结束后进入最终金币结算

## 四、数值总表（贯穿序章+正片）

| 数值 | 来源 | 作用范围 |
|---|---|---|
| `cash`（现金/金币） | 各场景决策结算 | 最终结局判定的核心指标 |
| `reputation`（声誉） | 部分场景决策 | 影响达能之争场景的初始筹码强度 |
| `resilience`（坚韧值） | 序章分支 | 影响广告豪赌失败时的损失折扣 |
| `negotiation_skill`（谈判技巧） | 序章"据理力争"分支 | 影响场景1田忌赛马的初始筹码加成 |
| `ahai_bond` | 序章分支 | 决定阿海是否在场景2（广告豪赌）以"帮手"身份出现，提供小幅加成 |

## 六、V1.0 优先落地范围

考虑到时间和精力，建议第一版只做以下最小闭环，验证整套系统可运行：

1. 序章：出生情节 + 农场篇（含分支点1、2），茶场篇可先简化为纯文字过场，二丫/赵伯支线后续再补
2. 正片：场景2（广告豪赌）+ 场景3（兼并）——这两个都是"决策+事件"机制，技术上最容易实现，优先跑通
3. 结局判定：先做"好结局/阶段性结局"两分支

**后续迭代顺序**：场景1和场景4的田忌赛马机制（涉及新的UI交互，稍复杂）→ 场景5解谜机制 → 场景6收尾 → 序章的二丫/赵伯支线补全
